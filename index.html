Trajetória e visão de negócio

Sou desenvolvedor full-stack e graduando em Bacharelado em Ciência de Dados pela UNIVESP. Atualmente atuo na Nova Smar S/A, onde desenvolvi e mantenho em produção um dashboard financeiro intranet integrado ao ERP TOTVS Protheus e Oracle PL/SQL, além de relatórios de estoque essenciais que viabilizaram a conclusão do inventário corporativo em tempo recorde em 2025.

Minha experiência técnica cobre todo o ciclo de engenharia de software: microsserviços e APIs corporativas em Java 21 / Spring Boot 3 (RabbitMQ, Redis Sliding Window), interfaces de alta performance em React 19 / Next.js 16 / TypeScript / Tailwind CSS v4 com suítes de testes automatizados (Vitest/JUnit), modelos preditivos de Machine Learning em Python (LightGBM, SHAP, Streamlit) e rotinas avançadas de banco de dados (Oracle PL/SQL, PostgreSQL, MySQL).

Antes da transição definitiva para a tecnologia, liderei por 5 anos uma operação própria de e-commerce, conquistando a qualificação de Mercadolíder em menos de 1 ano. Essa bagagem prática de negócio me permite projetar arquiteturas resilientes com foco em custos, integridade de dados e solução de dores reais de produto.
